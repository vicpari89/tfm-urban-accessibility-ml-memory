# TFM Auditor Skill

**Descripción**: Auditoría académica del TFM según convenciones UOC y enfoque de género.

## 1. ENFOQUE DE GÉNERO (según documento UOC)

### Lenguaje inclusivo
- [ ] Evitar generalizaciones en masculino genérico
  - Excepción aceptada: «el autor» y «el tutor» se refieren a Víctor y Antonio, personas concretas con ese género; no marcar.
- [ ] Usar dobletes: "el estudiante/la estudiante" o formas neutras
- [ ] Revisar sustantivos con sesgo de género (investigador/investigadora)
- [ ] Lenguaje sobre diversidad funcional: inclusivo, no paternalista

### Perspectiva de género en contenido
- [ ] ¿Se menciona diversidad de género en población estudiada?
- [ ] ¿Se consideran sesgos de género en metodología?
- [ ] ¿Hay equidad en ejemplos y referencias?
- [ ] ¿Se reconoce perspectiva de género en conclusiones?

### Cuidados especiales
- Evitar términos desactualizados para diversidad
- Reconocer aportaciones de mujeres/personas LGBTIQ+
- Evitar estereotipos

## 2. CONVENCIONES UOC (según UOC lengua-estilo)

### Citas y referencias
- [ ] Formato consistente: apellido, año (Harvard)
- [ ] Bibliografía alfabética ordenada
- [ ] URLs completas con fecha de acceso
- [ ] Diferenciación: citas directas vs. indirectas
- [ ] Citas directas: comillas + página exacta

### Estructura formal
- [ ] Títulos: capitalización consistente
- [ ] Números: norma (mil, 1.000, según estándar)
- [ ] Énfasis: solo negrita para conceptos clave
- [ ] Listas numeradas vs. viñetas (coherencia)

### Glosario
- [ ] Orden alfabético
- [ ] Abreviaciones consistentes
- [ ] Definiciones claras y breves

### Bibliografía
- [ ] Apellido, Nombre. (Año). *Título*. Editorial.
- [ ] Artículos: Apellido, Nombre. (Año). "Título". *Revista*, vol, pp.
- [ ] URLs: [Online]. Disponible en: URL. [Acceso: día/mes/año]
- [ ] Sin fechas de acceso para libros

## 3. VERIFICACIÓN RÁPIDA

| Elemento | Verificar |
|----------|-----------|
| Capítulos | Lenguaje inclusivo, coherencia formal |
| Tablas | Título, etiquetas, número figuras |
| Citas | Formato Harvard, página exacta |
| Referencias | Disponibilidad de URLs, fecha acceso |
| Glosario | Alfabético, definiciones claras |

---

**Uso**: Aplicar antes de cada entrega PEC para garantizar calidad formal y perspectiva inclusiva.
